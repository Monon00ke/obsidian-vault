# 📋 Шпаргалка: Как решать дифференциальные уравнения

Полная версия с определением типа уравнения и подробным ходом решения.

---

## Часть 0. Как определить тип уравнения

### Быстрый чек-лист

| Вопрос | Если ДА → тип уравнения |
|--------|--------------------------|
| Есть $y''$, $y'$, $y$ и правая часть? | Линейное 2-го порядка |
| Есть $M(x,y)dx + N(x,y)dy = 0$ и $\partial M/\partial y = \partial N/\partial x$? | В полных дифференциалах |
| Система из двух уравнений с $x'$ и $y'$? | Система линейных ДУ |
| Нет $y$ (или нет $x$)? | Понижение порядка |
| Есть $y^2$ и $y'$? | Риккати |
| Есть начальное условие $y(x_0)=y_0$? | Задача Коши (добавляется в конце) |

## 1. Линейное неоднородное уравнение 2-го порядка

### Как узнать
- Уравнение вида: $y'' + p y' + q y = f(x)$
- $p, q$ — числа (постоянные коэффициенты)
- Есть вторая производная

### Ход решения

**Шаг 1. Решаем однородное уравнение**
$$
y'' + p y' + q y = 0
$$

Составляем характеристическое уравнение:
$$
r^2 + p r + q = 0
$$

Решаем квадратное уравнение и получаем корни $r_1, r_2$.

**Варианты корней:**

| Корни | Общее решение однородного |
|-------|---------------------------|
| $r_1 \neq r_2$ | $y_{\text{одн}} = C_1 e^{r_1 x} + C_2 e^{r_2 x}$ |
| $r_1 = r_2 = r$ | $y_{\text{одн}} = (C_1 + C_2 x) e^{r x}$ |
| Комплексные $a \pm bi$ | $y_{\text{одн}} = e^{a x}(C_1 \cos bx + C_2 \sin bx)$ |

**Шаг 2. Ищем частное решение $y_{\text{ч}}$**

Смотрим на правую часть $f(x)$ и подбираем вид $y_{\text{ч}}$:

| $f(x)$ | Вид $y_{\text{ч}}$ | Когда умножать на $x$ |
|--------|---------------------|------------------------|
| Полином $P_n(x)$ | $A_n x^n + \dots + A_0$ | если 0 — корень |
| $e^{ax}$ | $A e^{ax}$ | если $a$ — корень |
| $P_n(x) e^{ax}$ | $(A_n x^n + \dots) e^{ax}$ | если $a$ — корень |
| $\cos bx$ или $\sin bx$ | $A \cos bx + B \sin bx$ | если $\pm bi$ — корни |
| $P_n(x) \cos bx$ | $(A_n x^n + \dots)\cos bx + (B_n x^n + \dots)\sin bx$ | если $\pm bi$ — корни |
| $e^{ax} \cos bx$ | $e^{ax} [(A_n x^n + \dots)\cos bx + \dots]$ | если $a \pm bi$ — корни |

**Шаг 3. Метод неопределённых коэффициентов**

Подставляем $y_{\text{ч}}$ в исходное уравнение, приравниваем коэффициенты при одинаковых функциях и решаем систему относительно $A, B, C, \dots$

**Шаг 4. Общее решение**
$$
y = y_{\text{одн}} + y_{\text{ч}} = C_1 \dots + C_2 \dots + y_{\text{ч}}
$$

## 2. Уравнение в полных дифференциалах

### Как узнать
- Уравнение записано в форме: $M(x,y)\, dx + N(x,y)\, dy = 0$
- Выполняется условие: $\dfrac{\partial M}{\partial y} = \dfrac{\partial N}{\partial x}$

### Ход решения

**Шаг 1. Проверка**
Вычисляем обе частные производные и сравниваем.

**Шаг 2. Находим потенциал $F(x,y)$**

Интегрируем $M$ по $x$:
$$
F(x,y) = \int M(x,y)\, dx + g(y)
$$

**Шаг 3. Находим $g(y)$**

Берём производную $F$ по $y$ и приравниваем к $N$:
$$
\frac{\partial F}{\partial y} = N
$$
Отсюда находим $g'(y)$, интегрируем и получаем $g(y)$.

**Шаг 4. Записываем решение**
$$
F(x,y) = C
$$

## 3. Система линейных дифференциальных уравнений

### Как узнать
- Две переменные $x(t), y(t)$
- Две производные $x', y'$
- Система из двух уравнений

### Ход решения

**Шаг 1. Однородная система**

Записываем в матричной форме:
$$
\mathbf{X}' = A \mathbf{X}
$$

Находим собственные значения $\lambda$ из уравнения:
$$
\det(A - \lambda I) = 0
$$

Для каждого $\lambda$ находим собственный вектор $\mathbf{v}$.

**Шаг 2. Общее решение однородной системы**

$$
\mathbf{X}_{\text{одн}} = C_1 \mathbf{v}_1 e^{\lambda_1 t} + C_2 \mathbf{v}_2 e^{\lambda_2 t}
$$

**Шаг 3. Частное решение неоднородной системы**

Смотрим на правую часть:
- Если $\mathbf{f}(t) = \mathbf{p} e^{kt}$ → ищем $\mathbf{X}_{\text{ч}} = \mathbf{a} e^{kt}$
- Если $k$ — собственное значение → умножаем на $t$

**Шаг 4. Общее решение**
$$
\mathbf{X} = \mathbf{X}_{\text{одн}} + \mathbf{X}_{\text{ч}}
$$

## 4. Уравнение, не содержащее $y$ (или $x$)

### Как узнать
- В уравнении **нет** $y$ (только $y', y''$)
- Или **нет** $x$ (только $y, y', y''$)

### Ход решения

**Вариант A: Нет $y$**

Делаем замену:
$$
p = y' \quad \Rightarrow \quad y'' = \frac{dp}{dx}
$$

Получаем уравнение первого порядка относительно $p(x)$.

Решаем его, потом интегрируем:
$$
y = \int p\, dx + C_1
$$

**Вариант B: Нет $x$**

Делаем замену:
$$
p = y' \quad \Rightarrow \quad y'' = p \frac{dp}{dy}
$$

Получаем уравнение относительно $p(y)$.

## 5. Уравнение Риккати

### Как узнать
- Уравнение вида: $y' = P(x) + Q(x)y + R(x)y^2$
- Есть квадратичный член по $y$

### Ход решения

**Шаг 1. Найти частное решение $y_0(x)$**

Обычно подбираем:
- Постоянную $y_0 = c$
- Или простую функцию (линейную, $1/x$ и т.д.)

**Шаг 2. Замена**
$$
y = y_0 + \frac{1}{v}
$$

**Шаг 3. Получаем линейное уравнение**

После подстановки получаем линейное уравнение относительно $v$.

**Шаг 4. Решаем линейное уравнение** (формула или интегрирующий множитель)

**Шаг 5. Возвращаемся к $y$**

## 6. Задача Коши

### Как узнать
- Есть начальное условие вида $y(x_0) = y_0$ или $y'(x_0) = y'_0$

### Ход решения

**Шаг 1.** Находим **общее решение** (с произвольными константами $C_1, C_2, \dots$)

**Шаг 2.** Подставляем начальное условие в общее решение

**Шаг 3.** Получаем систему уравнений относительно $C_1, C_2, \dots$

**Шаг 4.** Решаем систему и находим числовые значения констант

**Шаг 5.** Подставляем найденные константы обратно в общее решение

## Сводная таблица

| Тип | Форма уравнения | Первое действие | Метод |
|-----|------------------|------------------|-------|
| Линейное 2-го порядка | $y'' + py' + qy = f(x)$ | Характеристическое уравнение | Неопределённые коэффициенты |
| Полный дифференциал | $M dx + N dy = 0$ | Проверить $\partial M / \partial y = \partial N / \partial x$ | Поиск потенциала $F$ |
| Система | $\mathbf{X}' = A\mathbf{X} + \mathbf{f}$ | Собственные значения матрицы $A$ | Экспоненциальные решения |
| Нет $y$ | $F(x, y', y'') = 0$ | $p = y'$, $y'' = dp/dx$ | Понижение порядка |
| Риккати | $y' = P + Qy + Ry^2$ | Найти частное решение $y_0$ | Замена $y = y_0 + 1/v$ |
| Задача Коши | + начальное условие | Найти общее решение | Подстановка условия |

---

**Главное правило:**  
Сначала всегда решаем **однородную** часть, потом ищем **частное** решение неоднородной.
