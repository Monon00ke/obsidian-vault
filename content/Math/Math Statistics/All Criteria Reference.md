## 1. ПАРАМЕТРИЧЕСКИЕ КРИТЕРИИ

---

### 1.1. z-критерий (известна σ)

**Когда:** сравнение выборочного среднего с гипотетическим, **σ генеральной совокупности известна**.

**Формула:**
$$z = \frac{\bar{x} - \mu_0}{\sigma / \sqrt{n}}$$

**Условия:**
- $n$ большой ($n \geq 30$) или данные нормальны
- $\sigma$ известна

**Критическое значение:** $z_{\alpha}$ из стандартного нормального распределения

**Пример:**
$$H_0: \mu = 10,\; \bar{x}=9.2,\; \sigma=2,\; n=25$$
$$z = \frac{9.2 - 10}{2/\sqrt{25}} = -2.0$$
$z_{0.05} = -1.645 \Rightarrow -2.0 < -1.645 \Rightarrow$ отвергаем $H_0$

**Python:**
```python
from scipy import stats
z = (xbar - mu0) / (sigma / sqrt(n))
p = stats.norm.cdf(z)  # односторонний
```

---

### 1.2. t-критерий (Стьюдента)

**Когда:** сравнение среднего с гипотетическим, **σ неизвестна** (оцениваем через $s$).

**Формула:**
$$t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}$$

**Условия:**
- Данные приблизительно нормальны
- $\sigma$ неизвестна

**Критическое значение:** $t_{\alpha;\,n-1}$ из распределения Стьюдента

**Пример:**
$$H_0: \mu = 60,\; \bar{x}=55,\; s=3,\; n=37$$
$$t = \frac{55 - 60}{3/\sqrt{37}} \approx -10.14$$
$t_{0.05;36} \approx -1.69 \Rightarrow -10.14 < -1.69 \Rightarrow$ отвергаем $H_0$

**Python:**
```python
t_stat, p = stats.ttest_1samp(data, mu0)  # двусторонний
t_stat, p = stats.ttest_1samp(data, mu0, alternative='less')
```

---

### 1.3. F-критерий (Фишера) — сравнение дисперсий

**Когда:** проверка равенства двух дисперсий.

**Формула:**
$$F = \frac{s_1^2}{s_2^2} \quad\text{(большая дисперсия в числителе)}$$

**Условия:**
- Обе выборки независимы
- Обе из нормального распределения

**Степени свободы:** $df_1 = n_1 - 1,\; df_2 = n_2 - 1$

**Пример:**
$$H_0: \sigma_1^2 = \sigma_2^2,\; s_1=4,\; s_2=7,\; n_1=n_2=15$$
$$F = \frac{7^2}{4^2} = 3.0625,\; df_1=14,\; df_2=14$$
$F_{0.01}(14,14) \approx 3.74 \Rightarrow 3.0625 < 3.74 \Rightarrow H_0$ не отвергается

**Python:**
```python
F = s1**2 / s2**2
p = 2 * min(stats.f.cdf(F, df1, df2), 1 - stats.f.cdf(F, df1, df2))
```

---

### 1.4. Критерий Пирсона χ² (согласия)

**Когда:** проверка соответствия эмпирического распределения теоретическому.

**Формула:**
$$\chi^2 = \sum_{i=1}^{k} \frac{(O_i - E_i)^2}{E_i}$$

**Степени свободы:** $df = k - 1 - m$, где $m$ — число оцененных параметров

**Условия:**
- $E_i \geq 5$ для всех ячеек (иначе объединяем)
- Наблюдения независимы

**Схема:**
1. Разбить на $k$ интервалов
2. Посчитать $O_i$ (наблюдаемые частоты)
3. Вычислить $E_i = n \cdot P_i$ (теоретические вероятности)
4. Найти $\chi^2_{набл}$
5. Сравнить с $\chi^2_{кр}(df; \alpha)$

**Пример (проверка нормальности):**
$$n=209,\; k=11,\; \bar{x}\approx1.26,\; s\approx0.498$$
$$df = 11 - 3 = 8$$
$\chi^2_{набл} \approx 21.8,\; \chi^2_{0.05;8} \approx 15.507$
$21.8 > 15.507 \Rightarrow$ отвергаем нормальность

**Python:**
```python
chi2_stat, p = stats.chisquare(f_obs, f_exp)
```

---

### 1.5. Критерий Пирсона χ² (независимости)

**Когда:** проверка независимости двух категориальных признаков в таблице сопряжённости.

**Формула:**
$$\chi^2 = n \sum_{i,j} \frac{(n_{ij} - E_{ij})^2}{n_{i\cdot}n_{\cdot j}}$$
где $E_{ij} = \frac{n_{i\cdot} \cdot n_{\cdot j}}{n}$

**Степени свободы:** $df = (r-1)(c-1)$

**Пример:**
$\chi^2 = 30,\; df = 4,\; \chi^2_{0.05;4} \approx 9.49$
$30 > 9.49 \Rightarrow$ признаки зависимы

**Python:**
```python
chi2, p, dof, expected = stats.chi2_contingency(table)
```

---

### 1.6. ANOVA (однофакторный дисперсионный анализ)

**Когда:** сравнение средних трёх и более групп.

**Формулы:**
$$SSB = \sum_{i=1}^{k} n_i (\bar{x}_i - \bar{x})^2$$
$$SSW = \sum_{i=1}^{k} \sum_{j=1}^{n_i} (x_{ij} - \bar{x}_i)^2$$
$$F = \frac{SSB / (k-1)}{SSW / (n-k)}$$

**Условия:**
- Нормальность внутри групп
- Равенство дисперсий (гомоскедастичность)
- Независимость наблюдений

**Пример:**
$$SSB=13.5,\; SSW=6,\; k=3,\; n=9$$
$$F = \frac{13.5/2}{6/6} = \frac{6.75}{1} = 7.0$$
$p \approx 0.027 < 0.05 \Rightarrow$ группы различаются

**Python:**
```python
F, p = stats.f_oneway(group1, group2, group3)
```

---

### 1.7. Коэффициент корреляции Пирсона

**Когда:** измерение линейной связи между двумя количественными переменными.

**Формула:**
$$r = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2 \cdot \sum (y_i - \bar{y})^2}}$$

**Проверка значимости:**
$$t = \frac{r\sqrt{n-2}}{\sqrt{1-r^2}} \sim t_{n-2}$$

**Пример:** $r \approx 0.895$ — сильная положительная связь

**Python:**
```python
r, p = stats.pearsonr(x, y)
```

---

### 1.8. Множественный коэффициент корреляции

**Когда:** связь одной переменной с несколькими другими.

**Формула:**
$$R_{1(2,3)}^2 = \frac{r_{12}^2 + r_{13}^2 - 2 r_{12} r_{13} r_{23}}{1 - r_{23}^2}$$

**Проверка $H_0: R=0$:**
$$F = \frac{R^2 / k}{(1-R^2) / (n-k-1)} \sim F_{k,\,n-k-1}$$

**Пример:**
$r_{12}=0.45,\; r_{13}=0.5,\; r_{23}=0.3,\; n=33$
$$R^2 = \frac{0.2025 + 0.25 - 0.135}{1 - 0.09} \approx 0.349,\; R \approx 0.591$$
$$F = \frac{0.349/2}{0.651/30} \approx 8.04 > 3.32 \Rightarrow \text{значим}$$

**Python:**
```python
# из множественной регрессии
model = sm.OLS(y, X).fit()
R = np.sqrt(model.rsquared)
```

---

### 1.9. Линейная регрессия (МНК)

**Когда:** моделирование зависимости $Y$ от $X$.

**Формулы:**
$$\hat{\theta}_1 = \frac{n\sum XY - \sum X \sum Y}{n\sum X^2 - (\sum X)^2}$$
$$\hat{\theta}_0 = \bar{Y} - \hat{\theta}_1 \bar{X}$$

**Проверка $\theta_1$:**
$$t = \frac{\hat{\theta}_1}{SE(\hat{\theta}_1)} \sim t_{n-2}$$

**Пример:**
$$\hat{Y} = 0.6 + 1.8X$$
$t = 3.576 > 3.182 \Rightarrow$ наклон значим

**Python:**
```python
slope, intercept, r, p, se = stats.linregress(x, y)
```

## 2. НЕПАРАМЕТРИЧЕСКИЕ КРИТЕРИИ

---

### 2.1. ρ Спирмена (Spearman)

**Когда:** ранговый коэффициент корреляции — связь между порядковыми переменными или когда нарушена нормальность.

**Формула:**
$$r_s = 1 - \frac{6\sum d_i^2}{n(n^2-1)}$$
где $d_i = R_{x_i} - R_{y_i}$

**Условия:** нет необходимости в нормальности

**Пример:**
$\sum d^2 = 2,\; n=6$
$$r_s = 1 - \frac{6\cdot2}{6\cdot35} \approx 0.943$$
Крит. знач. для $n=6,\; \alpha=0.05$: $0.829$
$0.943 > 0.829 \Rightarrow$ значимо

**Python:**
```python
rho, p = stats.spearmanr(x, y)
```

---

### 2.2. τ Кендалла (Kendall)

**Когда:** альтернатива Спирмену, более робастная к выбросам.

**Формула:**
$$\tau = \frac{C - D}{n(n-1)/2}$$
где $C$ — число согласных пар, $D$ — число несогласных

**Пример:**
$C=9,\; D=1,\; n=5$
$$\tau = \frac{9-1}{10} = 0.8$$

**Python:**
```python
tau, p = stats.kendalltau(x, y)
```

---

### 2.3. Критерий Вилкоксона (Wilcoxon / Mann-Whitney)

**Когда:** сравнение двух независимых выборок (непараметрическая альтернатива t-критерию).

**Статистика:** $AB$ (число пар, где элемент X больше элемента Y)

**Пример:**
$AB = 58,\; n_1=n_2=11,\; \alpha=0.05$
Критическая область: $[52; 79]$
$58 \in [52;79] \Rightarrow H_0$ не отвергается

**Python:**
```python
stat, p = stats.mannwhitneyu(x, y, alternative='two-sided')
```

---

### 2.4. Критерий Колмогорова-Смирнова (K-S)

**Когда:** сравнение двух эмпирических распределений или эмпирического с теоретическим.

**Формула:**
$$D_{n,m} = \sup_x |F_n(x) - G_m(x)|$$

**Критическое значение:**
$$D_{кр} = \lambda_\alpha \sqrt{\frac{n+m}{n \cdot m}}$$
где $\lambda_{0.05} \approx 1.36$

**Пример:**
$D_{7,7} = 0.8571,\; D_{кр} = 1.36 \cdot \sqrt{\frac{14}{49}} \approx 0.728$
$0.8571 > 0.728 \Rightarrow$ распределения различаются

**Python:**
```python
stat, p = stats.ks_2samp(x, y)  # две выборки
stat, p = stats.kstest(data, 'norm', args=(mean, std))  # с теоретическим
```

---

### 2.5. Критерий Краскела-Уоллиса (Kruskal-Wallis)

**Когда:** непараметрическая альтернатива ANOVA (сравнение 3+ групп).

**Формула:**
$$H = \frac{12}{N(N+1)} \sum_{i=1}^{k} \frac{R_i^2}{n_i} - 3(N+1)$$
где $R_i$ — сумма рангов в i-й группе

**Пример:**
$H \approx 12.93,\; p \approx 0.0016 < 0.05 \Rightarrow$ группы различаются

**Python:**
```python
H, p = stats.kruskal(group1, group2, group3)
```

---

### 2.6. Критерий Джонкхира-Терпстра (Jonckheere-Terpstra)

**Когда:** проверка упорядоченного тренда (альтернатива: $Med_1 \leq Med_2 \leq \dots \leq Med_k$ с хотя бы одним строгим неравенством).

**Формула:** считаем количество пар $\text{sign}(x_{bj} - x_{ai})$ для всех $a < b$

**Пример:**
$JT = 71$ из $75$ возможных пар
$p \ll 0.001 \Rightarrow$ тренд значим (время сборки уменьшается с опытом)

**Python:**
```python
# нет в scipy напрямую, но можно посчитать вручную:
from scipy.stats import norm
```

---

### 2.7. V Крамера (Cramér's V)

**Когда:** сила связи для таблиц сопряжённости $r \times c$.

**Формула:**
$$V = \sqrt{\frac{\chi^2}{n \cdot \min(r-1, c-1)}}$$

**Интерпретация:**
- $V < 0.1$ — слабая
- $0.1 \leq V < 0.3$ — умеренная
- $V \geq 0.3$ — сильная

**Пример:** $V \approx 0.224$ — умеренная связь

**Python:**
```python
V = np.sqrt(chi2 / (n * min(r-1, c-1)))
```

---

### 2.8. λ Гудмана-Краскала (Goodman-Kruskal lambda)

**Когда:** асимметрическая мера связи — насколько знание $X$ улучшает предсказание $Y$.

**Формула:**
$$\hat{\lambda}_B = \frac{\sum_i \max_j n_{ij} - \max_j n_{\cdot j}}{n - \max_j n_{\cdot j}}$$

**Интерпретация:** доля снижения ошибки предсказания

**Пример:** $\hat{\lambda}_B \approx 0.037$ — всего 3.7% улучшения (очень слабая связь)

**Python:**
```python
row_maxes = np.max(table, axis=1).sum()
col_max = np.max(table.sum(axis=0))
lam = (row_maxes - col_max) / (n - col_max)
```

---

### 2.9. τ Гудмана-Краскала (Goodman-Kruskal tau)

**Когда:** асимметрическая мера с учётом всех категорий (отличие от λ — использует все данные, а не только моду).

**Формула:**
$$\hat{\tau}_B = \frac{n \sum_{i,j} \frac{n_{ij}^2}{n_{i\cdot}} - \sum_j n_{\cdot j}^2}{n^2 - \sum_j n_{\cdot j}^2}$$

**Интерпретация:** на сколько процентов уменьшается ошибка предсказания

**Пример:** $\hat{\tau}_B \approx 0.073$ — 7.3% улучшения

## 3. ТОЧЕЧНЫЕ И ИНТЕРВАЛЬНЫЕ ОЦЕНКИ

---

### 3.1. Точечные оценки

| Параметр | Оценка | Формула |
|----------|--------|---------|
| Мат. ожидание $\mu$ | $\bar{x}$ | $\frac{1}{n}\sum x_i$ |
| Дисперсия $\sigma^2$ | $s^2$ (исправленная) | $\frac{1}{n-1}\sum (x_i - \bar{x})^2$ |
| $p$ (биномиальное) | $\hat{p}$ | $\frac{m}{n}$ |
| $\lambda$ (Пуассона) | $\hat{\lambda}$ | $\bar{x}$ |

### 3.2. Свойства оценок

- **Несмещённость:** $E[\hat{\theta}] = \theta$ (пример: $\bar{x}$ — несмещённая для $\lambda$ Пуассона)
- **Состоятельность:** $\hat{\theta} \xrightarrow{p} \theta$ при $n \to \infty$
- **Эффективность:** минимальная дисперсия среди всех несмещённых

### 3.3. Метод максимального правдоподобия (МП)

**Схема:**
1. Записать функцию правдоподобия $L(\theta) = \prod f(x_i;\theta)$
2. Взять $\ln L$
3. Найти производную по $\theta$, приравнять к 0
4. Решить уравнение — получить $\hat{\theta}_{МП}$

**Пример (Пуассон):** $X_i \sim Pois(\lambda)$
$$L(\lambda) = \prod \frac{\lambda^{x_i} e^{-\lambda}}{x_i!}$$
$$\ln L = \sum x_i \ln\lambda - n\lambda - \sum\ln(x_i!)$$
$$\frac{d}{d\lambda} = \frac{\sum x_i}{\lambda} - n = 0 \Rightarrow \hat{\lambda} = \bar{x}$$

## 4. РОБАСТНОСТЬ

### 4.1. B-робастность (ограниченная)

Оценка B-робастна, если её чувствительность к выбросам ограничена.

- **Среднее арифметическое $\bar{x}$** — НЕ робастно (один выброс может утащить куда угодно)
- **Медиана** — робастна
- **Усечённое среднее (trimmed mean)** — робастно (отбрасывает крайние процентили)
- **Устойчивые оценки (M-оценки Хубера)** — робастны

### 4.2. Точка разрушения (breakdown point)
- Среднее: $1/n \to 0$
- Медиана: $\approx 50\%$
- Усечённое среднее: доля отбрасывания

## 5. ВЫБОР КРИТЕРИЯ: БЛОК-СХЕМА

```
Какой вопрос?
│
├─ Один признак?
│  ├─ Среднее vs константа?
│  │  ├─ σ известна → z-критерий
│  │  └─ σ неизвестна → t-критерий
│  ├─ Распределение vs теоретическое?
│  │  └─ χ² согласия (или K-S)
│  └─ Дисперсия vs константа?
│     └─ χ² для дисперсии (или F)
│
├─ Два признака?
│  ├─ Зависимость?
│  │  ├─ Количественные, нормальные → Пирсон r
│  │  ├─ Количественные, ненормальные → Спирмен / Кендалл
│  │  └─ Категориальные → χ² независимости
│  ├─ Различие средних?
│  │  ├─ Независимые → t-критерий (или Вилкоксон)
│  │  └─ Зависимые → парный t (или знаковый)
│  └─ Различие дисперсий?
│     └─ F-критерий
│
├─ Три+ группы?
│  ├─ Средние равны? → ANOVA
│  ├─ Медианы равны? → Краскел-Уоллис
│  └─ Есть тренд? → Джонкхир-Терпстра
│
└─ Регрессия?
   ├─ Одна переменная → парная регрессия (linregress)
   └─ Несколько → множественная регрессия
```

## 7. ПОЛЕЗНЫЕ ФОРМУЛЫ

### Вариационный ряд
- Размах: $R = x_{max} - x_{min}$
- Длина интервала: $h \approx R / k$
- Эмпирическая функция распределения: $F^*(x) = \frac{n_x}{n}$, где $n_x$ — число наблюдений $< x$

### Ряд распределения
- $\mathbb{E}(\xi) = \sum k \cdot P(\xi = k)$
- $\mathbb{E}(\xi^2) = \sum k^2 \cdot P(\xi = k)$
- $\mathbb{D}(\xi) = \mathbb{E}(\xi^2) - (\mathbb{E}(\xi))^2$

### Геометрическое распределение (число неудач до успеха)
- $P(v = k) = (1-p)^k \cdot p,\; k = 0,1,2,\dots$
- $E(v) = \frac{1-p}{p}$

### Равномерное распределение $U[0,1]$
- $E(\xi_i) = \frac{1}{2}$
- $D(\xi_i) = \frac{1}{12}$
- Для $\xi = \frac{1}{n}\sum \xi_i$: $E(\xi) = \frac{1}{2},\; D(\xi) = \frac{1}{12n}$

import numpy as np

# t-критерий (одновыборочный)

stats.chi2_contingency(table)

F = s1**2 / s2**2
p = stats.f.cdf(F, df1, df2)

# ANOVA
stats.f_oneway(g1, g2, g3)

# Пирсон
stats.pearsonr(x, y)

# Спирмен
stats.spearmanr(x, y)

# Кендалл
