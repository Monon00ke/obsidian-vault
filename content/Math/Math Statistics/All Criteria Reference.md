# 📊 Все критерии матстата простыми словами

Перед тем как читать про критерии, разберёмся с терминами.

## Термины, которые везде встречаются

| Термин | Что это значит простыми словами |
|--------|----------------------------------|
| **$H_0$ (нулевая гипотеза)** | То, что мы проверяем. Обычно «ничего не изменилось» или «разницы нет» |
| **$H_1$ (альтернатива)** | Противоположное — «разница есть» |
| **$\alpha$ (уровень значимости)** | Насколько мы готовы ошибиться. Обычно берут **0.05** = 5% |
| **p-value** | «Вероятность, что мы ошиблись, отвергнув $H_0$». Если **p < 0.05** → отвергаем $H_0$ |
| **Критическое значение** | Граница: если наша статистика больше/меньше неё — гипотезу отвергаем |
| **Степени свободы (df)** | Примерно «сколько чисел можно менять, не ломая систему» |
| **Статистика критерия** | Число, которое мы считаем по формуле, и сравниваем с таблицей |
| **Выборка** | Несколько наблюдений (не все, а только часть) |
| **Генеральная совокупность** | Все люди/объекты вообще |

## ПАРАМЕТРИЧЕСКИЕ КРИТЕРИИ

Параметрические = требуют, чтобы данные были **нормально распределены** (как колокол). Проверяют **параметры** (среднее, дисперсию).

---

### 1.1. z-критерий

**Когда нужен:** хотим проверить, отличается ли среднее выборки от какого-то числа, и **мы знаем $\sigma$** (стандартное отклонение генеральной совокупности).

**Простой пример:** говорят, что средний IQ = 100. Мы проверили 50 своих друзей, получили средний IQ = 105. Мы знаем, что стандартное отклонение IQ в популяции = 15. Действительно ли наши друзья умнее среднего, или это случайность?

**Формула:**
$$z = \frac{\bar{x} - \mu_0}{\sigma / \sqrt{n}}$$

**Что тут что:**
- $\bar{x}$ — среднее нашей выборки (105)
- $\mu_0$ — предполагаемое среднее (100)
- $\sigma$ — известное стандартное отклонение (15)
- $n$ — объём выборки (50)

**Считаем:**
$$z = \frac{105 - 100}{15 / \sqrt{50}} \approx \frac{5}{2.12} \approx 2.36$$

**Как решить:**
1. Считаем z по формуле → **2.36**
2. Смотрим критическое значение $z_{0.05} = 1.96$ (для двустороннего теста)
3. Если $|z| > 1.96$ — отвергаем $H_0$
4. $2.36 > 1.96$ → **Да, IQ друзей значимо выше**

**Python:**
```python
from scipy import stats
z = (105 - 100) / (15 / 50**0.5)
p = 2 * (1 - stats.norm.cdf(abs(z)))  # двусторонний
# p ≈ 0.018 < 0.05 → значимо
```

---

### 1.2. t-критерий (Стьюдента)

**Когда нужен:** то же самое, но **$\sigma$ НЕИЗВЕСТНА** (почти всегда в реальной жизни).

**Простой пример:** поставщик сказал, что его пшеница даёт 60 ц/га. Мы проверили 37 полей и получили среднее 55 ц/га, стандартное отклонение 3 ц/га. Врёт поставщик?

$$t = \frac{55 - 60}{3 / \sqrt{37}} \approx -10.14$$

**Как решить:**
1. $t = -10.14$
2. Критическое значение $t_{0.05; 36} \approx -1.69$ (смотрим в таблице Стьюдента, df = n-1 = 36)
3. $-10.14 < -1.69$ → отвергаем $H_0$
4. **Поставщик врёт**, урожайность реально ниже 60 ц/га

**Python:**
```python
t_stat, p = stats.ttest_1samp(data, 60)
# если p < 0.05 → H0 отвергаем
```

---

### 1.3. F-критерий (Фишера) — сравнение дисперсий

**Когда нужен:** проверить, **одинаковая ли разбросанность** (дисперсия) у двух групп.

**Простой пример:** два станка делают болты. Первый стабильнее (дисперсия 4²=16), второй болтается (дисперсия 7²=49). Одинаковы ли дисперсии?

$$F = \frac{s_2^2}{s_1^2} = \frac{49}{16} = 3.0625$$

**Как решить:**
1. Делим **большую** дисперсию на **меньшую**: $F = 3.0625$
2. Степени свободы: $df_1 = n_1-1 = 14$, $df_2 = n_2-1 = 14$
3. $F_{кр}(0.01; 14,14) \approx 3.74$
4. $3.0625 < 3.74$ → **не можем сказать, что дисперсии разные**

**Python:**
```python
F = s2**2 / s1**2
p = 2 * min(stats.f.cdf(F, df1, df2), 1 - stats.f.cdf(F, df1, df2))
```

### 1.4. χ² Пирсона (критерий согласия)

**Когда нужен:** проверить, **подчиняются ли данные какому-то распределению** (например, нормальному).

**Простой пример:** мы 209 раз записали, сколько покупок делают люди за день. Получили гистограмму. Похоже ли это на нормальное распределение «колоколом»?

**Как решить:**
1. Разбиваем данные на интервалы (11 штук)
2. Для каждого интервала: $O_i$ — сколько реально попало, $E_i$ — сколько должно быть по теории
3. $\chi^2 = \sum \frac{(O - E)^2}{E}$
4. Степени свободы: $df = k - 1 - m$, где $m$ — сколько параметров оценили (для нормального: среднее и стд = 2)
5. $\chi^2_{набл} \approx 21.8$, $\chi^2_{0.05; 8} \approx 15.5$
6. $21.8 > 15.5$ → **распределение НЕ нормальное**

**Python:**
```python
chi2, p = stats.chisquare(f_obs, f_exp)
```

---

### 1.5. χ² независимости

**Когда нужен:** проверить, **зависит ли один признак от другого** в таблице.

**Простой пример:** 300 человек. У каждого записали тип темперамента (холерик, сангвиник, флегматик) и профессию (врач, инженер, артист). Есть ли связь?

$$\chi^2 = n \sum_{i,j} \frac{(n_{ij} - E_{ij})^2}{n_{i\cdot}n_{\cdot j}}$$

**Пример:** $\chi^2 = 30$, $df = (3-1)(3-1) = 4$, $\chi^2_{0.05;4} \approx 9.49$

$30 > 9.49$ → **связь есть!**

Дополнительно считаем **V Крамера** (сила связи):
$$V = \sqrt{\frac{30}{300 \cdot 2}} \approx 0.224$$ — умеренная связь

**Python:**
```python
chi2, p, dof, expected = stats.chi2_contingency(table)
```

### 1.6. ANOVA (сравнение 3+ групп)

**Когда нужен:** хотим сравнить **средние трёх и больше групп**.

**Простой пример:** три метода обучения. Проверили студентов — средние баллы: 4.0, 2.0, 5.0. Есть ли разница между методами?

**Идея:** смотрим, разброс **между** группами больше, чем разброс **внутри** групп. Если между больше — группы реально разные.

$$F = \frac{SSB / (k-1)}{SSW / (n-k)}$$

**Пример:** $F = 7.0$, $p \approx 0.027$
$0.027 < 0.05$ → **методы обучения дают разный результат**

**Python:**
```python
F, p = stats.f_oneway(group1, group2, group3)
```

### 1.7. Корреляция Пирсона ($r$)

**Когда нужен:** измерить **линейную связь** между двумя числами.

**Простой пример:** чем больше часов подготовки, тем выше балл на экзамене?

$$r = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2 \cdot \sum (y_i - \bar{y})^2}}$$

**Как понять $r$:**
- $r = 1$ — идеальная прямая зависимость (чем больше X, тем больше Y)
- $r = -1$ — идеальная обратная (чем больше X, тем меньше Y)
- $r = 0$ — нет линейной связи
- $|r| > 0.7$ — сильная, $0.3-0.7$ — умеренная, $<0.3$ — слабая

**Пример:** $r \approx 0.895$ — **сильная связь**: больше часов → выше балл

**Python:**
```python
r, p = stats.pearsonr(x, y)
```

---

### 1.8. Множественная корреляция ($R$)

**Когда нужен:** измерить, **насколько одна переменная связана с несколькими другими сразу**.

**Простой пример:** зависит ли зарплата одновременно от возраста, образования и опыта работы?

$$R_{1(2,3)}^2 = \frac{r_{12}^2 + r_{13}^2 - 2 r_{12} r_{13} r_{23}}{1 - r_{23}^2}$$

**Пример:** $R \approx 0.591$ — умеренная связь веса одновременно с ростом и возрастом

**Python:**
```python
# строишь регрессию, смотришь R²
model = sm.OLS(y, X).fit()
R_squared = model.rsquared
```

---

### 1.9. Линейная регрессия

**Когда нужен:** предсказать $Y$ по $X$.

**Простой пример:** хотим предсказать цену квартиры по её площади.

$$\hat{Y} = \theta_0 + \theta_1 X$$

$$\hat{\theta}_1 = \frac{n\sum XY - \sum X \sum Y}{n\sum X^2 - (\sum X)^2}$$
$$\hat{\theta}_0 = \bar{Y} - \hat{\theta}_1 \bar{X}$$

**Пример:** $X = \{1,2,3,4,5\}$, $Y = \{3,5,4,7,11\}$
$$\hat{Y} = 0.6 + 1.8X$$
То есть: если X=1, предсказанный Y = 0.6+1.8 = 2.4

**Python:**
```python
slope, intercept, r, p, se = stats.linregress(x, y)
```

## НЕПАРАМЕТРИЧЕСКИЕ КРИТЕРИИ

Непараметрические = **не требуют нормальности**. Работают с **рангами** (местами по порядку), а не с самими числами.

---

### 2.1. ρ Спирмена

**Когда нужен:** измерить связь, **когда данные не нормальные** или связь не линейная, а просто «чем больше X, тем больше Y».

**Простой пример:** оценили 6 смартфонов по цене (X) и качеству (Y). Есть ли связь?

**Как работает:**
1. Сортируем X от меньшего к большему, даём ранги (1, 2, 3, ...)
2. То же для Y
3. Считаем разницу рангов $d = R_x - R_y$
4. $$r_s = 1 - \frac{6\sum d^2}{n(n^2-1)}$$

**Пример:** $\sum d^2 = 2$, $n=6$
$$r_s = 1 - \frac{6 \cdot 2}{6 \cdot 35} \approx 0.943$$
Критическое значение для n=6: 0.829
$0.943 > 0.829$ → **связь есть** (чем дороже, тем качественнее)

**Python:**
```python
rho, p = stats.spearmanr(x, y)
```

---

### 2.2. τ Кендалла

**Когда нужен:** альтернатива Спирмену, **когда много выбросов** или данные с повторениями.

**Простой пример:** те же смартфоны, но у некоторых одинаковая цена.

$$\tau = \frac{C - D}{n(n-1)/2}$$

**Что тут что:**
- $C$ — сколько пар, где X и Y растут в одну сторону (согласные)
- $D$ — сколько пар, где в разные (несогласные)

**Пример:** $C=9$, $D=1$, $n=5$
$$\tau = \frac{9-1}{10} = 0.8$$

**Python:**
```python
tau, p = stats.kendalltau(x, y)
```

---

### 2.3. Вилкоксона (Манн-Уитни)

**Когда нужен:** сравнить **две группы**, когда данные не нормальные.

**Простой пример:** две группы мышей — одна на обычном корме, другая на витаминах. У кого вес больше?

**Как работает:**
1. Берём все значения из обеих групп
2. Сортируем, даём ранги
3. Считаем $AB$ — сколько раз значение из группы X больше значения из группы Y
4. Если $AB$ выходит за границы — группы отличаются

**Пример:** $AB = 58$, $n_1=n_2=11$
Критические границы: $[52; 79]$
$58 \in [52; 79]$ → **не можем сказать, что группы отличаются**

**Python:**
```python
stat, p = stats.mannwhitneyu(x, y)
```

---

### 2.4. Колмогоров-Смирнов

**Когда нужен:** сравнить **два распределения** целиком (не только среднее, а всю форму).

**Простой пример:** одинаково ли распределены зарплаты в IT и в производстве?

$$D_{n,m} = \max |F_n(x) - G_m(x)|$$

То есть: берём точку, где накопленные доли отличаются сильнее всего. Если это отличие слишком большое — распределения разные.

**Пример:** $D = 0.857$, критическое $D_{кр} \approx 0.728$
$0.857 > 0.728$ → **распределения разные**

**Python:**
```python
stat, p = stats.ks_2samp(x, y)
```

---

### 2.5. Краскела-Уоллиса

**Когда нужен:** ANOVA, но **для ненормальных данных**. Сравнение 3+ групп.

**Простой пример:** три рецепта пирога — какой вкуснее? Оцениваем по 10-балльной шкале. Данные не нормальные, используем ранги.

$$H = \frac{12}{N(N+1)} \sum_{i=1}^{k} \frac{R_i^2}{n_i} - 3(N+1)$$

**Пример:** $H \approx 12.93$, $p \approx 0.0016$
$0.0016 < 0.05$ → **рецепты дают разный вкус**

**Python:**
```python
H, p = stats.kruskal(group1, group2, group3)
```

---

### 2.6. Джонкхира-Терпстра

**Когда нужен:** есть **упорядоченные** группы (1-й курс, 2-й курс, 3-й курс) и мы ожидаем **тренд** (растёт или падает).

**Простой пример:** ожидаем, что с опытом работы время сборки детали уменьшается. Проверяем новичков, 1-3 года, профи.

**Как работает:**
1. Берём каждую пару «из более ранней группы — из более поздней»
2. Если значение уменьшается, считаем 1
3. Если больше пар показывают тренд, чем нет — тренд есть

**Пример:** $JT = 71$ из 75 пар подтверждают тренд
$p \ll 0.001$ → **время сборки реально падает с опытом**

---

### 2.7. V Крамера

**Когда нужен:** измерить **силу связи** после χ² независимости (чтобы не просто сказать «связь есть», а понять, насколько она сильная).

$$V = \sqrt{\frac{\chi^2}{n \cdot \min(r-1, c-1)}}$$

**Как понять:**
- $V < 0.1$ — слабая связь
- $0.1 \leq V < 0.3$ — умеренная
- $V \geq 0.3$ — сильная

**Пример:** $V \approx 0.224$ — умеренная связь между темпераментом и профессией

---

### 2.8. λ Гудмана-Краскала

**Когда нужен:** насколько **знание одного признака помогает предсказать другой** в таблице сопряжённости.

**Простой пример:** знаем, на каком транспорте человек ездит (авто/автобус/метро). Насколько это помогает угадать, в каком районе он живёт?

$$\hat{\lambda}_B = \frac{\sum_i \max_j n_{ij} - \max_j n_{\cdot j}}{n - \max_j n_{\cdot j}}$$

**Пример:** $\hat{\lambda}_B \approx 0.037$ — знание транспорта улучшает предсказание района **всего на 3.7%** (слабая связь)

---

### 2.9. τ Гудмана-Краскала

**Когда нужен:** то же, что λ, но **точнее** — учитывает все категории, а не только самую частую.

**Пример:** $\hat{\tau}_B \approx 0.073$ — улучшение предсказания на 7.3%

## ДОПОЛНИТЕЛЬНЫЕ ПОНЯТИЯ

### Ряд распределения

Просто таблица: «сколько раз выпало каждое значение» и «какая вероятность каждого».

| k | P(ξ=k) |
|---|--------|
| 0 | 0.006 |
| 1 | 0.092 |
| 2 | 0.398 |
| 3 | 0.504 |

Мат. ожидание: $E(\xi) = 0 \cdot 0.006 + 1 \cdot 0.092 + 2 \cdot 0.398 + 3 \cdot 0.504 = 2.4$
Дисперсия: $D(\xi) = E(\xi^2) - (E(\xi))^2 = 6.22 - 5.76 = 0.46$

### Вариационный ряд и гистограмма

Разбиваем данные на корзинки (интервалы) и смотрим, сколько попало в каждую.

| Интервал (см) | Сколько человек |
|---------------|:--------------:|
| 150–155 | 1 |
| 155–160 | 3 |
| 160–165 | 2 |
| ... | ... |

Рисуем столбики = **гистограмма**. Если столбики похожи на колокол — данные нормальны.

### Эмпирическая функция распределения ($F^*(x)$)

Доля наблюдений, которые **меньше** данного x. Растёт ступеньками от 0 до 1.

### Несмещённость оценки

Оценка **несмещённая**, если в среднем (по многим выборкам) она попадает в цель.

**Пример:** среднее арифметическое — несмещённая оценка для $\lambda$ Пуассона. То есть $E[\bar{X}] = \lambda$.

### Робастность

Оценка **робастна**, если выбросы её не портят.

- Среднее — **НЕ** робастно (один выброс может изменить его сильно)
- Медиана — робастна
- Усечённое среднее (отбрасываем 10% крайних значений) — робастно

**Пример:** данные: 1, 2, 3, 4, **100**
- Среднее: 22 (выброс утащил)
- Усечённое среднее (отбросили 1 и 100): (2+3+4)/3 = 3 (нормально)
- Медиана: 3

## КАК ВЫБРАТЬ КРИТЕРИЙ (шпаргалка)

```
Что хотим узнать?
│
├─ Отличается ли среднее от числа?
│  → t-тест (σ неизвестна) или z-тест (σ известна)
│
├─ Есть ли связь между двумя переменными?
│  ├─ Обе числа, нормальные → Пирсон (r)
│  ├─ Обе числа, ненормальные → Спирмен или Кендалл
│  └─ Категории (цвет, профессия) → χ²
│
├─ Отличаются ли две группы?
│  ├─ Нормальные → t-тест
│  └─ Ненормальные → Вилкоксон
│
├─ Отличаются ли 3+ группы?
│  ├─ Нормальные → ANOVA
│  └─ Ненормальные → Краскел-Уоллис
│
├─ Есть ли тренд по группам?
│  → Джонкхир-Терпстра
│
└─ Подчиняются ли данные нормальному распределению?
   → χ² согласия или Колмогоров-Смирнов
```

## PYTHON CHEATSHEET (простой)

```python
import numpy as np
from scipy import stats

# t-тест (среднее против числа)
stats.ttest_1samp(данные, число)

# t-тест (две группы)
stats.ttest_ind(группа1, группа2)

# ANOVA (три+ группы)
stats.f_oneway(г1, г2, г3)

# Корреляция Пирсона
stats.pearsonr(цены, качество)

# Корреляция Спирмена
stats.spearmanr(цены, качество)

# Корреляция Кендалла
stats.kendalltau(цены, качество)

# χ² независимости
stats.chi2_contingency(таблица)

# Манн-Уитни (Вилкоксон)
stats.mannwhitneyu(группа1, группа2)

# Колмогоров-Смирнов
stats.ks_2samp(выборка1, выборка2)

# Проверка на нормальность
stats.kstest(данные, 'norm', args=(среднее, стд))

# Краскел-Уоллис
stats.kruskal(г1, г2, г3)

# Линейная регрессия
```
